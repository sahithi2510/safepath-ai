## 1. Overview & Objectives

Milestone 15 establishes **SHAP (SHapley Additive exPlanations)** explainability for SafePath AI models using `shap==0.46.0`. It provides transparent, mathematically verified explanations of road-segment risk predictions for both the primary **XGBoost** model and the **Random Forest** baseline.

### Primary Goals:
1. Initialize and maintain `shap.TreeExplainer` instances for trained XGBoost and Random Forest models.
2. Provide **local explanations** for individual road segments, detailing positive (risk-increasing) and negative (risk-decreasing/protective) feature contributions.
3. Mathematically verify the **additive efficiency property**:
   $$\mathbb{E}[f(X)] + \sum_{i=1}^{15} \phi_i = f(x)$$
   within a strict numerical tolerance ($|\epsilon| \le 10^{-4}$).
4. Provide **global explanations** summarizing mean absolute feature importance across the road network.
5. Strictly adhere to **non-causal, associative phrasing**, preventing invalid claims that model associations constitute real-world physical causation.
6. Clearly distinguish between **raw model output**, **predicted relative risk score**, and the **user-facing safety score** ($1.0 - \text{risk}$).

## 2. Scientific & Safety Requirements

### 2.1 Synthetic Data Provenance Warning
In accordance with `AGENTS.md` §2.1 & §2.4:
* The current model was trained and evaluated on synthetic fixtures ([scripts/fixtures/mock_training_dataset.csv](file:///c:/Users/91967/OneDrive/Desktop/Safe%20path%20AI/scripts/fixtures/mock_training_dataset.csv)).
* **Scientific Honesty Disclosure:** Any feature attribution generated by this pipeline demonstrates **software correctness, algorithm mechanics, and mathematical reconstruction** — **NOT empirical real-world street safety**.
* Every explanation response includes `is_synthetic_demonstration = True` and explicit warning disclaimers.

### 2.2 Non-Causal Interpretation
* **Attribution vs. Causation:** SHAP values describe how features change the model's mathematical output relative to its expectation in the training distribution. They **do not establish real-world physical causality**.
* **Forbidden Phrasing:** The system strictly rejects causal claims such as *"poor lighting caused the danger"* or *"installing lights will make this road safe"*.
* **Standard Phrasing:** The system phrases all factors associatively:
  - *"Active street lighting score associates with lower model predicted risk."*
  - *"Higher localized crime density (500m) associates with higher model predicted risk."*
* Every explanation output embeds a mandatory scientific disclaimer:
  > *"These explanations reflect the machine learning model's statistical feature attributions, NOT direct physical measurements or real-world causal proofs. Features identify correlation in training distributions, not real-world causation."*

## 3. Mathematical Formulation & Additive Reconstruction

### 3.1 Efficiency Property
For tree ensemble models, SHAP values guarantee the local accuracy (efficiency) property:
$$f(x) = \phi_0 + \sum_{i=1}^{M} \phi_i(x)$$
where $\phi_0 = \mathbb{E}[f(X)]$ is the model's base expected value, $\phi_i(x)$ is the SHAP attribution for feature $i$, and $M = 15$ is the total feature count.

### 3.2 Output Space by Architecture

| Architecture | Model Output $f(x)$ | Base Value $\phi_0$ | Predicted Risk Score | Reconstruction Verification |
| :--- | :--- | :--- | :--- | :--- |
| **XGBoost Classifier** | Margin / Log-odds | $\mathbb{E}[\text{margin}]$ | $\sigma(f(x)) = \frac{1}{1 + e^{-f(x)}}$ | $\|\phi_0 + \sum_{i=1}^{15} \phi_i - \text{margin}\| \le 10^{-4}$ |
| **Random Forest Classifier** | Class probability | $\mathbb{E}[P(Y=1)]$ | $f(x) = P(Y=1)$ | $\|\phi_{0,1} + \sum_{i=1}^{15} \phi_{i,1} - P(Y=1)\| \le 10^{-4}$ |
| **Regression Models** | Continuous risk | $\mathbb{E}[y]$ | $\min(1.0, \max(0.0, f(x)))$ | $\|\phi_0 + \sum_{i=1}^{15} \phi_i - f(x)\| \le 10^{-4}$ |

*Verified Error in Test Suite:* Measured reconstruction errors are $< 10^{-6}$, reliably satisfying the $\le 10^{-4}$ validation threshold.

### 3.3 Score Separation
1. **Model Output ($f(x)$):** Raw score generated by trees (margin in log-odds space or tree vote fraction).
2. **Predicted Risk Score:** Calibrated relative risk in range $[0.0, 1.0]$.
3. **User-Facing Safety Score:** Complementary score presented to end users:
   $$\text{safety\_score} = 1.0 - \text{predicted\_risk\_score} \in [0.0, 1.0]$$
4. **Risk Category:** Application-defined threshold mapping (`VERY_LOW`, `LOW`, `MODERATE`, `HIGH`, `VERY_HIGH`).

## 7. Remaining Limitations

1. **Synthetic Data Fixtures:** Models currently explain synthetic training associations. Attributions will change when trained on empirical real-world crime data.
2. **Interaction Effects:** Current implementation reports first-order Shapley feature attributions. Second-order feature interaction effects (e.g., lighting $\times$ nighttime) can be explored via `shap_interaction_values` once empirical data is ingested.
3. **Background Distribution Assumption:** TreeExplainer path-dependent marginalization assumes feature independence in off-manifold evaluation. For production, interventional TreeExplainer with empirical background sets can be evaluated if correlations are severe.
