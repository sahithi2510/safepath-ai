# Models Directory

This directory stores trained model artifacts.

> **These files are NOT in Git.** See `.gitignore`.
> They are large binary files that must be generated by running the training scripts.

## Directory Structure (after training)

```
models/
├── random_forest/
│   ├── model.joblib        Trained Random Forest model
│   ├── scaler.joblib       Fitted MinMaxScaler
│   ├── feature_names.json  Ordered list of feature names
│   └── metadata.json       Training date, dataset info, metrics
├── xgboost/
│   ├── model.joblib        Trained XGBoost model
│   ├── scaler.joblib       Fitted MinMaxScaler
│   ├── feature_names.json  Ordered list of feature names
│   └── metadata.json       Training date, dataset info, metrics
└── README.md               This file
```

## How to Train Models

```bash
cd scripts
python train_random_forest.py
python train_xgboost.py
```

See `scripts/README.md` for prerequisites.

## Model Metadata Format

Each `metadata.json` must contain:
```json
{
  "model_type": "xgboost",
  "version": "1.0.0",
  "trained_at": "YYYY-MM-DD",
  "training_dataset": "description of dataset",
  "records_used": null,
  "features": [],
  "metrics": {
    "status": "NOT_YET_evaluated"
  },
  "notes": "Training notes"
}
```

> **IMPORTANT:** `metrics` must remain `NOT_YET_evaluated` until the model is actually evaluated.
> Never invent metric values.
